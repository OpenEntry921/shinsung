# 상고 주장별 반박 준비실 (2026-11-07)

## 기준과 보존

PR #36은 `08cda2a`로 main에 병합된 것을 Git 이력에서 확인했습니다. 해당 main에서 `codex/prepare-appeal-claims`를 분리했습니다. 기존 작업을 다시 쓰거나 기존 PR을 닫지 않습니다.

`/prepare/`의 인증된 첫 화면은 상고 주장별 준비표입니다. 기존 72개 점검표는 `/prepare/events/`, 기존 개별 `/prepare/events/Txx/`와 댓글 URL·앵커는 유지합니다. 일반 사이트의 사건·⑤ 의견·자료·댓글·메뉴·로그인은 수정하지 않습니다. 준비실 내부에서만 두 점검표를 오갑니다.

새 `AP26-…` ID는 원문 순서와 독립적인 의미 기반 ID입니다. 이미 의견이 연결된 ID를 변경하거나 다른 주장에 재사용하지 않습니다. 추가할 때 기존 ID는 남기고 표시 순서만 별도로 관리합니다. 사건 표시번호 대신 기존 키로 연결하며 제목과 실제 번호는 보존본에서 조회합니다. 예를 들어 건축 변경공사는 T03, 사임 관련은 T18입니다. T71은 표시41이고 T41은 표시42인 기존 대응도 그대로입니다.

## 실제 확인한 원문

이번에 전달된 `기소위원장 상고이유서(261106접수)-페이지-1.pdf`는 실제201쪽, `…-페이지-2.pdf`는185쪽으로 총386쪽입니다. 둘 다 스캔이며 텍스트 추출만으로 읽을 수 없었습니다. OCR 후 본문·목록 원본 이미지를 직접 대조했습니다. 파일명상 접수일 표기와 표지 공문의 시행일2026.11.04, 서면 작성일2026.10.26을 구별합니다. 실제 접수도장은 확인 완료로 처리하지 않습니다. 제출 명의는 안양노회 기소위원장 김승곤 목사이며 실제 작성자를 추정하지 않습니다.

1편 PDF1쪽은 송부 공문,2쪽은 빈쪽,3쪽은 상고이유서 신상 양식(인쇄1쪽)입니다. 별지 본문은 PDF4~18쪽(인쇄2~16쪽), 증거설명표·편철/규정 안내는 PDF19~21쪽(인쇄17~19쪽), 첨부 증거는 PDF22쪽부터입니다. 2편은 이어지는 증거 자료입니다. 번호는 각 분할 파일의 PDF 순서와 원본 인쇄쪽을 별도로 표기합니다.

상고 본문은 I~X의10개 상위 항목이며 원문 번호34개 단위(II는 표·설명 포함)를46개 세부 준비 항목으로 분리했습니다. 원문 소제목과 편집한 검토 소제목, 원문 번호와 검토 분할을 구분합니다. 원문 발췌는 짧은 핵심 인용이고 별도 편집 요지는 유보·예외와 요구를 함께 설명합니다. 전체 문맥을 읽는 열람본 링크도 있습니다. 반박은 주장에 직접 답하는 검토 초안이며 최종 제출문이 아닙니다.

`우리측_주장과증거_재검토_20261107.md`는 이번 환경에서 확보하지 못했고 사용자는 파일이 없다고 확인했습니다. 기존 preparation_data.json의 2차 요약은 기존 사건 점검표에만 원래 출처·한계 표시와 함께 보존합니다. 새 상고 항목을 그 요약에서 만든 것이 아닙니다.

직접 대조한 원심은 기존 개인정보 가림본 A12 PDF14~16쪽의 해당 부분입니다. 상고가 인용한 첨부 판결문의 PDF쪽과 A12 파일의 PDF쪽은 다를 수 있어 서로 바꾸지 않습니다. A12의 카페·배우자/감사·건축·헌금·계약·명예훼손 관련 이유는 별도 대조 요약으로 표시합니다. 양정·총회 적법 범위·공식 규정 적용본 등 직접 대조하지 않은 부분은 확인 대기입니다. 첨부 증거 전체의 진정성·입증을 확인했다는 뜻이 아닙니다.

## 원문 보호와 배포 파일

원본386쪽, OCR, 원본 래스터는 저장소 밖 비공개 작업 경로에만 보관했습니다. 원본을 static으로 복사하지 않습니다.

`portal/private_documents/appeal-body.redacted.pdf`는 별지 본문15쪽만 이미지로 평탄화한 별도 열람본입니다. 표지·주소/전화번호가 있는 신상 양식·증거첨부는 포함하지 않았고 마지막 서명·인장 영역을 제거한 뒤 새 JPEG 이미지만으로 PDF를 생성했습니다. 원본 PDF의 숨은 텍스트·첨부·metadata를 복제하지 않았습니다. 본문에 나오는 사건 관계자의 역할·이름과 금액·날짜는 직접 연락처와 혼동해 삭제하지 않습니다.

원본 PDF4쪽은 열람본1쪽, PDF18쪽은 열람본15쪽입니다. 인쇄2~16쪽에 대응하며 마지막 인쇄번호는 서명과 같은 가림 범위에 포함돼 있습니다. 인용 위치 정보로 마지막 쪽도 식별합니다. 결론 본문은 남아 있습니다.

열람본은 static 경로 밖 서버 파일이며 collectstatic 대상이 아닙니다. Git·Docker 예외는 이 한 파일만 허용합니다. 원본·다른 PDF는 계속 제외합니다. 준비실 인증을 거친 `/prepare/documents/appeal-body/`만 제공하고 SHA-256 불일치/누락이면404로 닫힙니다. 판결문 A12도 `/prepare/documents/judgment/`를 통해 같은 세션 확인과 해시 검사를 적용합니다. 기존 공개 가림본 A12의 기존 공개 범위 자체를 변경하지는 않습니다. 새 원문·JSON·의견 공개 API나 직접 경로를 만들지 않았습니다.

## 의견·검토 상태

일반 교인 로그인과 임시 공용 준비실 세션은 그대로 분리됩니다. 읽기·댓글·열람본 모두 같은 preparation_required 확인을 씁니다. 로그인 화면에 공용 접속값을 넣지 않습니다. 기존 no-store·Cookie Vary·noindex·CSRF를 유지합니다. 작성자 이름은 직접 적은 표기이며 개별 실명 인증이라고 표현하지 않습니다.

새 AppealComment와 AppealReview만 추가합니다. 0018은 두 CreateModel 작업뿐이며 기존 테이블의 삭제·초기화·댓글 이동이 없습니다. 원래 PreparationComment/PreparationReview와 일반 CaseComment는 건드리지 않습니다. 관리자는 기존 추가 인증 관리자 화면에서 새 검토 상태(미검토/자료 확보 중/검토 중/확정), 확보 기록과 초안을 관리할 수 있습니다. 모든 주장을 자동 확정하지 않습니다.

추가 콘텐츠 등록/시드는 필요 없습니다. 사용자 검토·병합 후 기존 배포의 migrate가0018을 적용합니다. 실제 운영 DB 변경 전 기존 운영 백업 정책을 지켜야 합니다. 이번 작업에서 운영 DB·배포·재시작은 실행하지 않았습니다. 데이터 영구 저장 조건도 이 작업으로 바뀌지 않습니다.
