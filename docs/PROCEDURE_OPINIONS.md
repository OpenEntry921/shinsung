# 08·17번 절차 비교 의견 반영

## 반영

- T08/표시08의 OP09를 사용자 제공 본문으로 교체했습니다. 함께 읽을 사건은17번과54번이며, 실제 이동 URL은 T17과T53입니다. 표시54와 안정 키T53을 혼동해 기존 사건 연결을 바꾸지 않았습니다.
- T17/표시17에는 중복되지 않는 OP16을 추가하고 T08로 연결했습니다.
- 두 표시 제목은 정확히 `⑤ 우리의 의견`입니다. 새 의견은 서버 본문이며 실제 성도 댓글로 생성하지 않습니다.

## 수정 원본과 재생성

`portal/opinion_updates.py`가 이번 두 의견의 편집 원본입니다. 사용자 요청의 제목·문단·자료 확인 범위를 그대로 저장합니다. `scripts/prepare_integrated_timeline.py`의 기존 명령이 MD를 읽은 뒤 이 업데이트를 적용하고 서버 템플릿을 렌더링합니다. 기존 MD에 구 의견이 있어도 재생성 시 이번 두 의견을 잃지 않습니다. OP09는 같은 ID로 교체하고 OP16은 한 번만 추가하며, 다른 사건이 같은 ID를 사용하는 경우 오류로 중단합니다. 생성 결과는 반복 실행해도 동일합니다.

`portal/templates/portal/integrated_case_reading.html`은 실제 렌더링 결과이며 원문 MD나 원자료를 공개 static에 복제하지 않았습니다. 변경된 링크는 검증된 표시 번호→안정 키 대응으로 생성합니다. 사용자 문장은 HTML 이스케이프하며 원문을 HTML로 실행하지 않습니다.

## 보존·검증

- 72개 사건의 순서와288개 기존 필드, 근거·쪽수·정적 자료 링크는 그대로입니다. T08/T17의 의견 외 본문과 나머지70개 사건 HTML은 이전 main과 바이트까지 일치합니다. 다른14개 의견도 그대로입니다.
- OP09 한 개 교체, OP16 한 개 추가로 전체 의견은16개입니다. 29번 송달 사건은 비교에 추가하지 않았습니다. 확인되지 않은 출석·정식 결의 유무·적법 인정·확정판결 등을 새 사실로 추가하지 않았습니다.
- 관련 회귀 테스트14개 통과. 가상 입력으로 업데이트 반복·충돌 거부·입력 보존·재생성·링크의 안정 키·이스케이프를 확인했습니다. 가상 성도의 기존 댓글 ID/내용/연결도 유지됐고 새로운 댓글을 만들지 않았습니다.
- PC1280/모바일390 Chromium에서 두 제목과 사용자 제공 문단을 실제 DOM과 대조하고,08↔17 이동과08→54 이동 링크를 확인했습니다. 네 영역·인증 차단·가로 넘침/번호 중복 없음 확인.
- 운영 DB·로그인·SMS·명부·관리자·자료파일·배포 설정은 변경하지 않았습니다. 운영 Cloudtype은 확인·배포하지 않았습니다.
