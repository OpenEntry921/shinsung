## Git 상태와 수동 진행

작업 변경 4개만 선택하는 명령은 다음과 같습니다. Mac의 별도 clone에 이 로컬 변경이 자동 전달된다고 가정하지 마세요.

```sh
git switch feat/timeline-opinion-drafts-20261104
git diff --check
git add scripts/prepare_integrated_timeline.py portal/templates/portal/integrated_case_reading.html portal/test_opinion_drafts.py docs/TIMELINE_OPINIONS_20261104.md

```

PR의 base는 `main`, compare는 `feat/timeline-opinion-drafts-20261104`입니다. PR 생성은 사용자가 추가 요청했으며 검토 요청·머지는 사용자가 진행합니다. 기준 커밋은 `1499619`입니다. 실제 제출 커밋과 원격 업로드·PR 생성 결과는 최종 보고에서 구분합니다. 기존 검사와 출처·의견 상태·주 연결 관계를 검토합니다. Cloudtype의 main 자동 배포 연결은 확인하지 못했으므로 머지 전 실제 운영 설정을 확인해야 합니다.
