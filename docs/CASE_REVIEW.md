# 사건 열람과 자료 등록

사건 열람은 게시 승인된 기존 사건·규정·설명 모델을 서버에서 조회합니다. 별도 `case-reading.body` 파일을 요구하지 않습니다. 인증된 활성 교인 또는 추가 인증을 마친 권한 있는 관리자에게만 전체 본문을 제공합니다. PC·모바일 모두 날짜 → 사건 경과 → 관련 규정 → 쟁점의 네 영역을 사건별 세로로 읽으며 검색·탭·접기·페이지 분할이 없습니다.

실제 자료는 `seed_demo`에 포함되지 않습니다. `APP_MODE=production`과 실제 인증이 필요하며 개발 OTP로 등록 자료를 열람할 수 없습니다. JSON의 reviewed 표시는 공식 판단 확인을 뜻하지 않습니다. 기존 `register_reviewed_materials` 명령이 DOCX의 허용 발췌 위치·원문 해시·인용을 직접 대조하고, 다른 작성자/검토자 및 게시 권한을 확인합니다. 공식 조문·결정 원자료가 미확인인 내용은 검토 문서의 설명/주장/의견으로 표시합니다. 관리자가 바꾼 자료나 비공개 전환은 반복 등록으로 덮어쓰지 않습니다.

[PostgreSQL 설정·SQLite 외부 백업·교인 이관·등록 명령·키 교체·운영 확인](POSTGRES_MIGRATION.md)을 순서대로 따르세요. 운영 SQLite 백업 외부 반출 확인 전 재배포하지 않습니다. 실제 원문·JSON·DB·본문·비밀값은 Git·정적 폴더·이미지에 넣지 않습니다. PostgreSQL 등록에서는 원문 DOCX도 관리자 전용 DB 바이너리로 보존합니다. 일반 PDF 파일 저장소의 영구 보존은 별도 운영 과제입니다. 사건 테이블과 기존 ID/게시글/문서 연결을 삭제하지 않습니다.
