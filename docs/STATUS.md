## 개발 시연 계정 자동 생성 변경 검증

배포 시작 스크립트가 마이그레이션 완료 후 `APP_MODE=development`일 때만 기존 `seed_demo`를 실행합니다. 가상 계정의 중복 생성과 기존 ID·게시글 연결 보존, 실제 명부가 있는 DB에서의 개인정보 없는 오류 및 시작 중단을 확인했습니다. 운영·누락·잘못된 모드 값에서는 샘플 생성이 실행되지 않고 개발용 인증번호를 표시하지 않습니다. 로그인 화면에는 개발 모드에만 시연 안내가 표시됩니다.

`APP_MODE=development .venv/bin/python manage.py test`로 기존 37개와 신규 7개, 총 44개 테스트가 통과했습니다. 시작 스크립트 테스트는 임시 DB에서 실제 Django 명령을 실행하고 최종 Gunicorn 명령만 기록용 실행 파일로 대체하여 마이그레이션 → 샘플 생성 → 역할 초기화 → 정적 파일 수집 → 서버 실행 명령의 순서와 기존 8000 포트 인자를 확인했습니다. 실제 Cloudtype 재배포는 수행하지 않았습니다. 셸 구문 검사, Django check, 마이그레이션 변경 없음, diff 공백 검사도 통과했습니다.

Cloudtype에서 이 변경이 배포 브랜치에 반영된 상태로 `APP_MODE=development`를 유지하고 재배포하면 가상 교인이 자동 생성됩니다. 자동 생성은 백업·복구가 아니며, 임시 디스크 소실 시 이전 게시글·자료를 복원하지 않습니다. 운영에는 영구 저장소와 실제 SMS 연결이 별도로 필요합니다.
