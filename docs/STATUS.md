브라우저 검증은 가상 교인과 잠시 생성한 가상 테스트 사건만 사용하고 제거했습니다. 실제 명부·사건·판결·조문 데이터는 없습니다. 기본 개발 DB의 가상 로그인은 `가상교인 / 01000000000`입니다.

추가 검증 재현:

```sh
APP_MODE=development .venv/bin/python manage.py test
.venv/bin/python scripts/verify_backup.py
.venv/bin/python scripts/build_cloud_image.py
.venv/bin/python scripts/verify_container.py
```

클라우드 Docker 빌드는 환경에 제공된 HTTPS 프록시의 이름 해석과 공개 CA bundle이 필요했습니다. 빌드 보조 스크립트가 지원 경로를 적용하며 공개 CA는 선택적 BuildKit secret mount로만 사용하여 이미지에 남기지 않습니다. TLS를 비활성화하지 않습니다. 일반 Cloudtype 빌드는 표준 Dockerfile을 사용합니다.

## 아직 연결·검증하지 않은 운영 항목

- 실제 SOLAPI 계정·발신번호·SMS 키와 잔액·발송 권한. 이 클라우드의 현재 네트워크에서 `api.solapi.com` 연결은 프록시 403으로 차단됨. 허용 도메인 추가는 초안에 저장했으며 현재 실행 정책 적용/실제 발송 검증과 구분함.
- 실제 운영 관리자 계정·각 계정의 TOTP. 관리자 계정과 비밀값을 시연용으로 임의 생성해 저장하지 않음.
- 운영 도메인·HTTPS 신뢰 프록시·실제 클라이언트 IP 전달 규칙, Cloudtype 프로젝트·디스크 연결·운영 환경변수. 로컬 컨테이너 재배포 보존은 검증했지만 실제 Cloudtype 배포/복구는 수행하지 않음.
- 처리 주체·문의 연락처·명부 이용 근거/동의 방식·보유기간의 운영 확정. `OPERATOR_NAME`, `OPERATOR_CONTACT` 설정 후 정책 페이지에 표시됨.
- PDF 가림 자동화·악성 문서 검사 연동, 백업 암호화/외부 저장소/예약 정리는 자동 제공하지 않음. 가림과 안전성은 관리자 수동 검사, 백업과 주기 실행은 운영 절차 필요.
- 완전 중복 이름+전화번호 명부는 자동 계정 구분하지 않음. 중복 행은 차단하고 관리자가 개인별 신원/기존 ID를 확인해야 함. 공용 번호는 개인별 예외 절차 사용.
- 비공개 자료 제출 양식은 텍스트만 지원. 교인의 파일 제출 경로는 관리자가 별도로 안전하게 안내하며 게시글 첨부는 제공하지 않음.
- 민감한 전체 과거 버전은 관리자만 열람하며 교인에게는 승인된 공개 정정·변경 요약만 표시함.
- GitHub API `api.github.com`은 현재 403으로 접근 불가하여 PR 자동 생성은 미완료. Git HTTPS read는 성공함. API 허용 도메인 추가를 환경 초안에 저장함.

댓글·좋아요·인기순·쪽지·투표·서명·AI 판정은 추가하지 않았습니다. 현재는 검증된 개발 환경이며 실서비스 운영 준비 완료로 보고하지 않습니다.

## 저장한 환경 설정

`install_script`, `start_skill`, 외부 도메인 `api.solapi.com`/`api.github.com`, 필요한 서버 환경변수 이름 `SMS_API_KEY`, `SMS_API_SECRET`, `SMS_SENDER`, `DJANGO_SECRET_KEY`, `ADMIN_MFA_SECRETS`, `OPERATOR_NAME`, `OPERATOR_CONTACT`를 환경 초안에 저장했습니다. 비밀값은 저장하지 않았습니다. 저장 자체는 실행 환경 적용 또는 게시가 아닙니다. 환경 설정에서 검토·저장 후 환경을 게시해야 새 작업에 재사용할 수 있습니다.

배포·명부 반영·자료 게시 순서는 [OPERATIONS.md](OPERATIONS.md)에 있습니다.
