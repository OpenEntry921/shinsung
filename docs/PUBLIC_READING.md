# 일반 사이트 공개 열람

## 공개 범위

GET/HEAD의 `/`, `/cases/archive/`, `/cases/<id>/`, `/cases/material/<key>/`, `/policy/`, `/health/`와 기존 정적 공개 자료를 허용합니다. 숫자 사건 URL의 기존 상세 URL 이동은 유지합니다. 사건 72개·⑤ 우리의 의견·상황판·로드맵과 사건 본문은 그대로 유지합니다. 검색엔진 색인 허용이나 SEO 변경은 포함하지 않습니다.

`/documents/<id>/reading/`은 published·가림 확인·공개 사건 연결·내부 메모 제외 조건을 모두 충족하는 기존 열람본만 제공합니다. 누락 파일은 404이며 원본으로 대체하지 않습니다. 원본은 기존 관리자 권한과 MFA가 필요합니다.

## 일반 인증과 기존 비공개 기록

`/login/`, `/apply/`, `/otp/`, `/exception/`은 홈페이지로 이동합니다. POST도 개인정보 저장·명부 대조·OTP·접속 수단 사용을 실행하지 않습니다. 기존 일반 로그아웃 POST는 일반 회원 인증 키만 제거하고 홈페이지로 이동합니다. CSRF 검사는 유지합니다.

익명 작성은 지원하지 않습니다. 비로그인 게시판·개인 요청·댓글 쓰기 요청은 403으로 거절합니다. 기존 실명 댓글·게시글과 요청 원문·답변은 공개하지 않으며 기존 권한 아래 보존합니다. 공개 페이지에는 댓글 수·실명 댓글·작성 버튼·일반 인증 안내를 표시하지 않습니다. 기존 유효 회원 세션은 원래 권한 아래 읽기와 본인 작성·수정·삭제가 가능하며, 새 일반 로그인이나 가입은 제공하지 않습니다. 공개 승인이 된 반론의 개인정보 제거 발췌만 표시합니다.

## 보호 영역과 세션

AccessMiddleware와 access_valid의 회원 승인·신원 확인 조건을 유지합니다. 준비 영역은 기존 별도 인증·1시간 만료·요청 제한·CSRF·전용 템플릿·데이터를 유지합니다. 일반 사이트 방문·구형 로그인 URL·무효 회원 세션 정리·일반 로그아웃이 별도 보호 영역의 유효 세션을 지우지 않습니다. 공개 HTML에는 해당 영역의 링크·인증 정보·내부 기록을 넣지 않습니다.

관리자·MFA·명부·접속 수단 발급·자료 가져오기와 원본 다운로드는 기존 인증·권한 검사를 유지합니다. no-store/private, noindex/nofollow와 공통 보안 미들웨어도 유지합니다. DB 초기화·데이터 삭제·마이그레이션 변경은 없습니다.

## 운영상 제한

기존 일반 접속 URL은 인증을 수행하지 않으므로 새로운 일반 회원 세션을 만들 수 없습니다. 작성·신규 접속 운영 방식은 별도 결정이 필요합니다. 운영자 개인정보 처리 주체와 문의 연락처는 기존 설정으로 공지해야 합니다. 과거 문서의 일반 로그인 복구·가입 절차는 이 공개 열람 전환 이후의 일반 진입 정책으로 사용하지 않습니다. 운영 배포와 자동 병합은 이 작업에 포함하지 않습니다.

## 검증

Django check·마이그레이션 변경 검사, 전체 Django 테스트, 브라우저의 데스크톱·모바일 직접 URL·새로고침·공개 파일 열람을 확인합니다. `portal.test_public_reading`은 익명 열람, 기존 비공개 데이터 비노출, 쓰기 거부, 구형 인증의 개인정보 미수집, 문서 공개 조건, 관리자·준비 영역 격리와 세션 보존을 검증합니다. 기존 준비·상고·접근 제어·문서 테스트는 보호 조건을 유지하고 일반 열람 기대값만 변경합니다.

검증 결과: 전체 Django 테스트 167개 통과, Django check 통과, 마이그레이션 변경 없음, 백업·복구 검증 통과. 실제 Chromium에서 1440px·390px의 직접 접속·새로고침, 72개 항목, 공개 PDF·이미지와 인증 UI 비노출을 확인했으며 가로 넘침·JavaScript 오류가 없었습니다.
