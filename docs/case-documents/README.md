# 신성커뮤니티교회 자료 정리본

2026년 11월 5일 작성. 제공된 ZIP의 28개 자료(PDF 27개, JPG 1개), 총 490쪽을 대상으로 정리했습니다.

## 처리 기준

- 사건 관련 이름, 직분, 주장·답변, 사건 날짜, 금액, 증거 내용은 유지합니다.
- 전화번호, 주민등록번호, 생년월일 등, 상세 주소, 계좌번호, 개인 이메일, 자필 서명·날인 등 직접적인 개인정보를 가립니다.
- 자필 탄원인명부는 이름을 남기고 생년월일·주소·연락처·서명/날인란을 가립니다.
- 개인정보가 첨부 증거에 반복 등장하는 경우도 같은 기준으로 처리합니다.
- 서명·인장이 인쇄된 이름·본문과 겹친 경우 겹친 부분의 글자가 함께 가려질 수 있습니다. 유색 인장은 인장의 유색 획을 제거하는 방법을 병행했습니다. 인장과 원래 글자가 겹친 부분은 원본 스캔의 한계가 있습니다.
- 원본 파일의 페이지 순서·쪽수는 유지했습니다. 일부 스캔본의 기울어짐·기존 흐림·원본 자체의 가림 표시는 그대로입니다.
- 처리본 PDF에는 가리기 전 이미지나 원문 텍스트를 포함하지 않았습니다. 이에 따라 PDF 내부의 본문 검색·텍스트 복사는 지원하지 않습니다.

## 파일 구성

- `static/case-documents/`: 개인정보 가림 사본. 기존 MD의 자료번호를 기준으로 파일명을 정리했습니다.
- `data/case_documents.json`: 자료번호, 원본 파일명, 상대경로, 웹 URL, 쪽수 연결표.
- `파일대응표.csv`: 사람이 확인할 수 있는 자료번호·원본 파일명 대응표.
- `개인정보_처리내역.csv`: 자료번호·페이지별 처리 항목. 개인정보 원문 값은 기록하지 않았습니다.

## 웹 연결

Django의 실제 static 설정에 맞게 `static/case-documents/`를 반영하고, 연결표의 `url`을 사용합니다. 예: `/static/case-documents/A01.pdf#page=7`.

PDF 쪽수는 표지·봉투를 포함하여 파일 처음부터 센 쪽수입니다. 인쇄된 본문 쪽수와 다를 수 있습니다.

기존 MD는 `10. 목사측 답변서3.pdf`를 `A11`, `11. 장로측 기소장 변경 허가신청서.pdf`를 `A11변경`으로 표기합니다. 이를 임의로 A10 등으로 바꾸지 않았습니다. `A11변경`의 웹 파일명만 `A11-change.pdf`로 두었습니다. C02는 원본 형식대로 JPG입니다.

이 묶음은 파일 정리 결과이며, 사이트에 반영하거나 외부에 게시한 이력은 포함하지 않습니다.
