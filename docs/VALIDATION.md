# 검증 결과와 운영 전 남은 작업

## 자동 검증

가상 명부·가상 전화번호·가상 자료만으로 pytest 실행: **24개 통과**. 실제 명부와 실제 사건 자료를 다운로드하거나 테스트에 사용하지 않았다.

검증 항목:

- 비로그인 페이지·API·문서 차단, 비활성·만료·로그아웃 세션 차단
- 일반 교인의 명부·내용 편집·관리 요청 접근 차단
- 명부 미등록자 인증 차단 및 일반화 응답
- 인증번호 재사용·만료·5회 대입·재요청 제한
- SMS 환경변수 미설정 시 발송 큐 처리 실패 및 인증 차단
- 공용 번호 차단, 개인 일회성 접속 발급 확인·만료 구조·재사용 차단
- 동명이인 비민감 구분, 관리자 명부 미리보기에서 누락·중복·공용 번호·0 복구 후보 확인
- 연락처 변경 시 세션 폐기, 명부 재업로드 ID·게시글 연결 유지, 누락 자동 삭제 금지
- 신규 등록 확인 요구와 오래된 명부 미리보기 반영 차단
- CSRF·요청 출처·작성자 ID/이름 조작 차단, 본인 글 수정·삭제 및 타인 수정·삭제 차단
- 사건 초안·검토·다른 관리자 게시, 게시 후 수정 시 재검토, 비공개 과거 버전
- 원본/열람본 권한, 승인·철회, 문서 강제 다운로드, 공개 경로 차단
- 셀프 게시 금지, 비공식 출처 조문 검증 거절
- 비공개 정정 요청, 관리자 처리 답변, 게시글 비공개 사유 및 본인 이의 확인
- 데이터 암호화와 no-store/CSP/noindex 헤더
- 관리자 비밀번호 + TOTP 검증, 번호 재사용 차단, 역할 분리
- 운영 쿠키 Secure/HttpOnly/SameSite
- DB 재시작 지속성과 암호화 백업·빈 인스턴스 복구·복구 후 세션 폐기

프런트엔드 JavaScript 문법 검사, Python 컴파일, 패키지 의존성 검사 통과. Gunicorn 2 workers / 2 threads와 실제 SMS 처리 훅을 사용한 서버 기동, health·로그인 HTML·관리자 로그인 HTML·운영 안내·정적 자산 HTTP 응답 검사 통과. 실제 브라우저 시각 검증은 수행하지 않았다.

## 운영 전 필수 확인

| 항목 | 현재 상태 / 필요한 조치 |
|---|---|
| Cloudtype | Dockerfile/상태 확인 구현. 실제 배포·영구 볼륨·권한·재배포 보존 확인은 미수행 |
| 실제 SMS | SOLAPI 코드 구현·공식 API 문서 확인. 키·발신번호 승인·잔액·실제 수신 확인 미연결 |
| 개인정보 정책 | 기본 접속 차단. 운영 주체·이용 근거·보유기간·문의처 확정·SMS 위탁 안내 반영 후 개방 |
| 관리자 | 개인별 관리자와 인증 앱 등록 필요. 초기 계정·공용 PIN 없음 |
| 실제 사건·헌법 | 데이터 없음. 공식 원문·당시 적용·반론 검증 후 등록 |
| PDF 가림 | 별도 도구 작업 + 작성자 외 수동 검토. 자동 redaction/OCR/악성코드 검사는 미구현 |
| 백업 | 스냅샷·복구 CLI 검증. 외부 백업 저장소·자동 일일 백업·보유기간 자동화는 미연결 |
| 모바일·브라우저 | 반응형 CSS와 서버 HTML 확인. 실제 브라우저/휴대전화 조작·시각 QA는 미수행 |
| 보안 | 핵심 기능 자동 검증. 외부 침투 테스트·부하 시험·SMS 비용 한도·신뢰 프록시 조정은 미수행 |
| 법적·편집 판단 | 자동 판단 없음. 개인정보 이용 근거·명예훼손·자료 공개 범위 및 편집 중립성은 담당자 확인 필요 |

프로토타입 화면만 있는 것은 아니며 서버 인증·DB·비공개 자료·관리 기능이 구현되어 있다. 그러나 위 운영 연동과 실제 배포 검증을 마치기 전에는 운영 가능한 서비스로 확정 보고하지 않는다.
