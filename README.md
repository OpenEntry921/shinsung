# 교회를 살리는 신도들의 모임 — 공개 열람 독립 앱

일반 콘텐츠를 로그인과 개인정보 입력 없이 열람하는 독립 Django 서버 앱입니다. 교회의 공식 홈페이지·교단의 판단 기관이 아닙니다. 실제 명부·신청·댓글 DB는 포함하지 않습니다. 기존 사건 30건의 HTML 본문은 저장소에 포함되어 있으므로 저장소 공개 범위와 자료 취급을 별도로 검토해야 합니다. 개발 변경은 별도 브랜치와 PR에서 검토합니다.

## 개발 환경

Python 3.12, Django 5.2, SQLite 영구 DB, 비공개 파일 저장을 사용합니다.

```sh
sh scripts/install.sh
APP_MODE=development .venv/bin/python manage.py test
. .venv/bin/activate
APP_MODE=development sh scripts/start-production.sh
```

개발은 `APP_MODE=development`, 운영은 `APP_MODE=production`을 사용합니다. 기본 시작에서는 샘플 교인이나 운영 데이터를 생성하지 않습니다. 기존 체크아웃을 사용하며 별도 Git worktree를 만들지 않습니다.

홈페이지, 72개 사건과 기존 사건 본문, 우리의 의견, 공동 상황판, 절차 로드맵 및 기존 공개용 자료는 GET/HEAD로 공개 열람할 수 있습니다. 일반 로그인·가입·OTP·예외 접속 URL은 홈페이지로 이동하며 제출된 개인정보로 인증하거나 접수하지 않습니다. 익명 작성은 제공하지 않습니다. 기존 실명 댓글·게시판·개인별 요청은 기존 유효 세션과 권한 아래 보존합니다. 신규 일반 접속 수단 발급과 작성 운영 방식은 별도 정비 대상입니다.

공개용 문서는 기존 게시 상태·가림 확인·공개 사건 연결 조건을 유지하며 내부 메모와 원본은 공개하지 않습니다. 운영 기능의 관리자 인증·권한·추가 인증은 유지합니다. 기존 보호 영역의 세션과 기능은 일반 공개 열람과 분리되어 있으며 해당 기능은 이번 변경에서 수정하지 않습니다. 자세한 변경 범위와 검증은 [공개 열람 전환 안내](docs/PUBLIC_READING.md)를 확인하세요.

관리자 계정은 `createsuperuser`로 별도 생성합니다. 관리자도 개인별 TOTP 추가 인증이 필수입니다. 공개 운영 전 설정·정책·자료 검증이 필요하며 현재 배포된 서비스가 아닙니다.

[운영·배포·자료 관리 안내](docs/OPERATIONS.md) · [구현 및 검증 범위](docs/STATUS.md)

`DATA_DIR` 설정과 실제 영구 디스크 연결은 다릅니다. 운영 전 외부 비공개 백업·복구와 동일 영구 볼륨 재시작 후 보존을 확인해야 합니다.

[인증된 사건 HTML 본문 안내](docs/CASE_REVIEW.md). 사건 30건의 발췌를 Django 템플릿에서 직접 렌더링합니다. 사건 DB·외부 본문 파일은 필요하지 않으며 기존 교인 인증 DB는 유지합니다. 이미 저장소에 있는 사건 본문은 유지하며 새 비공개 자료를 PR에 추가하지 않습니다. 운영 인증과 로그인 DB 보존은 별도 확인이 필요합니다.
